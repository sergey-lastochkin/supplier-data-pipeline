# Пайплайн товарных каталогов

[![CI](https://github.com/sergey-lastochkin/supplier-data-pipeline/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/sergey-lastochkin/supplier-data-pipeline/actions/workflows/ci.yml)

Проверка импорта, валидации и сопоставления карточек товаров. Код умеет сохранять контрольную точку, историю изменений и очередь спорных совпадений.

![Результат прогона каталогов](studies/openfacts-catalog-run-2026-08-10/graphs/source-metrics.svg)

Проверка выполнена на трёх открытых товарных каталогах: Open Food Facts, Open Beauty Facts и Open Pet Food Facts. Это ограниченная первая страница каждого каталога, а не полный каталог поставщика.

Получено 36 записей, 26 прошли проверку схемы. 10 записей без `product_name` отклонены до записи; ошибок источников не было. Прогон занял `15.162` с. Между каталогами не встретилось точного совпадения штрихкода и не появилось задач на ручную проверку.

Полные ответы API не добавлены в Git. Их SHA-256, размер, поля схемы и итог прогона сохранены в [results.json](studies/openfacts-catalog-run-2026-08-10/results.json) и [source-manifest.json](studies/openfacts-catalog-run-2026-08-10/source-manifest.json).

## Что делает код

- Адаптер проверяет `code` и `product_name` до записи, ограничивает частоту запросов и сохраняет контрольную точку после страницы.
- SQLite хранит промежуточные данные, снимки, изменения и решения по спорным совпадениям в одной успешной транзакции.
- Сильное точное совпадение принимается автоматически. Слабые и равные кандидаты остаются в очереди проверки.
- HTML и Playwright адаптеры покрыты локальными контрактными тестами. В этом прогоне они не обращались к внешним сайтам.

## Локальный запуск

```bash
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
PYTHONPATH=src .venv/bin/python -m pytest -q
PYTHONPATH=src .venv/bin/uvicorn supplier_pipeline.api:app
```

Контрольный API принимает только явно синтетические источники `localhost`, `.local` и `.test`; он не используется как произвольный crawler.

CI запускает `pytest`, `ruff` и `compileall` только на коде и локальных фикстурах. Он не запрашивает публичные каталоги и не запускает Playwright-браузер.

## Границы

- В публичном прогоне нет цен и остатков: эти значения не появляются, если API их не вернул.
- Одна страница поиска не является зеркалом каталога. Для массовой загрузки Open Facts рекомендует CSV или JSONL-выгрузки.
- `bsl/ImportEndpoint.bsl` показывает зависимую от конфигурации границу импорта 1С. Его не запускали в реальной информационной базе.
- Нет политики прокси, координации распределённых воркеров и миграций PostgreSQL. SQLite-режим рассчитан на один локальный процесс записи.
